# 国际化

后端通过 `config/translation.php` 配置多语言，语言包位于 `backend/resource/translations/`。

## 配置

```php
return [
    'locale'          => config('app.lang'),      // 默认语言，来自 config/app.php
    'fallback_locale' => ['zh_CN', 'en'],          // 回退顺序
    'path'            => base_path() . '/resource/translations',
];
```

支持的语言（枚举）：`app\enum\common\LangEnum`，常见为 `zh_CN`、`en`。

## 语言包文件

目录结构按语言分目录：

```
resource/translations/
├── zh_CN/
│   ├── system.php
│   └── common.php
└── en/
    ├── system.php
    └── common.php
```

文件返回键值数组：

```php
// zh_CN/system.php
return [
    'post_name_required' => '职位名称必须填写',
];

// en/system.php
return [
    'post_name_required' => 'Post name is required',
];
```

## 在代码中使用

```php
use function __; // 或 Illuminate 的 trans()

__('system.post_name_required');           // 按当前语言返回
trans('system.post_name_required');
```

当前语言由请求中的语言标识（通常来自 `Accept-Language` 或登录用户设置）决定，框架在中间件中解析并切换。

## 与前端 i18n 的关系

前端（admin / web）各自维护 `src/locales` 语言包，键名约定与后端保持一致（如 `plugin.name.key`）。接口返回的业务提示建议走后端翻译；前端展示文案走前端语言包，避免重复维护。

> 新增文案：后端加到 `resource/translations/<lang>/*.php`，前端加到对应 locale 文件，键名对齐。
