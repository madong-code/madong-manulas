# v5.1.0 更新日志

> 发布日期：2026-07-22（alpha）

本文记录 v5.1.0 的变更。升级前请先阅读[升级指南](./upgrade.md)与 [v5.0 更新日志](./v5.0.md)。

---

## 🚀 多租户 SaaS 模板体系

### 新增能力

- 全新设计多租户模板表结构
- 搭建租户数据同步模型，支持平台模板一键同步至租户
- 新增模板初始化种子数据，适配系统配置、字典、菜单模板导入能力
- 开放模板管理接口路由，新增菜单模板迁移命令

### 优化重构

- 补全模板服务字段能力，优化同步逻辑、清理冗余调试日志

### 问题修复

- 修正订阅权限树模板菜单表名注释与匹配细节

## 🔒 安装器与租户隔离增强

### 新增能力

- 启用安装检测中间件，区分页面 / API 请求，精准放行安装路由

### 优化重构

- 收紧租户字段隔离策略，安装器适配多租户模板种子数据初始化

## ⚡ 租户自动化同步能力

### 新增能力

- 新增 Redis 队列消费者，实现租户字典异步同步
- 租户创建时自动同步系统配置、字典、前端菜单模板

## ⏰ 多租户定时任务升级

### 新增能力

- 新增平台端运维服务，支持任务容量告警、调度配置迁移与 DTO 字段扩展

### 优化重构

- 定时任务全面适配多租户架构，支持租户上下文注入与透传

### 问题修复

- 对齐调度进程监听配置，修复前端构建联动异常

## 👤 会员模块迭代

### 新增能力

- 会员登录返回权限码，新增登出黑名单校验机制

### 优化重构

- 重构会员账单分页逻辑，完善签到、补签数据层与业务逻辑
- 统一手机绑定响应结构，重构会员登出整体流程

## 🛡 平台超管隔离与安全优化

### 优化重构

- 平台控制器按业务域重构目录结构，规范代码分层
- 强化记事本、用户信息接口的租户过滤与用户 ID 校验逻辑
- 精简 JWT 鉴权冗余 try/catch 逻辑，直接透传校验结果，提升接口性能
- 统一全局用户 ID 获取规则，增强多租户 Token 存储与刷新安全机制

### 问题修复

- 优化超管隔离策略，修复登出异常、头像上传路由问题

## 📌 菜单权限、组件与杂项优化

### 新增能力

- 菜单颜色统一 Hex 格式，新增配置分组枚举
- 增强站点路由菜单权限过滤能力，支持配置动态下发
- 上传组件支持 Base64 上传，增强配置容错能力
- 补充英文国际化通用翻译词条

### 问题修复

- 修复终端命令枚举 GBK 编码中文乱码问题
- 适配插件 `plugin:` 前缀，修复插件菜单 `module` 字段判断异常

## 🌐 Web 前端

重构会员、初始化、菜单、通知、布局、暗黑模式全量前端体系。

### 优化重构

- 重构会员全套页面与逻辑，适配新接口、全局 Store，全量支持中英文 i18n 国际化
- 重构站点初始化逻辑与全局状态，拆分 `nav` / `member` / `headerActions` 独立模块，支持权限过滤
- 重构三套布局、菜单与移动端抽屉，统一全局 SCSS 主题变量
- 调整 Nuxt 路由配置，清理冗余插件与废弃 Store

### 新增能力

- 新增 `menu-builder` 骨架构建器与 `routes-collector`，支持前后端混合路由合并去重
- 新增独立 `notify` 消息插件，实现未读徽章能力，完成登录态、菜单逻辑解耦
- 新增暗黑模式工具、布局组合式方法
- 新增 `.env.integrated` 配置、`dayjs` 依赖与 `date` 日期工具

## 🏛 平台端（platform）

### 优化重构

- 平台端按业务域重构 API、视图、语言包，拆分多模块目录结构
- 统一弹窗、表格、预览组件渲染逻辑
- 全量重构记事本目录、文档与编辑器面板，适配新版核心接口
- 清理废弃监控日志、旧菜单模板等冗余代码资源

### 新增能力

- 新增 `cell-json` / `cell-tags` 渲染组件

### 问题修复

- 补齐组件默认属性，修复空断言、未使用变量等 Lint 校验错误

## ⚙️ 管理端（admin）

### 优化重构

- 清理 Demo 示例页面与资源管理器冗余模块
- 统一表单、预览组件默认值与全局渲染规范
- 重构记事本、定时任务页面，适配新版业务架构
