# v5.0.1 更新日志

> 发布日期：2026-07-01

本文记录 v5.0.1 的变更。升级前请先阅读[升级指南](./upgrade.md)。

---

### 新增功能

- admin 模块新增 `key-value-editor` 键值编辑组件
- 集成 `wangeditor` 富文本插件，admin 端新增富文本组件
- admin 模块新增树结构叶子节点 id 集合获取方法

### 问题修复

- 优化 admin 端 `ApiDict` 组件，无 `code` 参数时返回空数组

### 优化调整

- 调整 admin 模块 `Page` 组件引入方式
- 调整 platform 模块 `Page` 页面引入逻辑
- 全局更新项目依赖
- 更新 `effects`、`plugins` 目录插件依赖包

---

> 上一版本见 [v5.0.0 更新日志](./v5.0.0.md)。
