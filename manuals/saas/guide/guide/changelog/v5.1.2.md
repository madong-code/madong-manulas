# v5.1.2 更新日志

> 发布日期：2026-08-04

本文记录 v5.1.2 的变更，涉及仓库：`backend`、`template/web`、`template/mono`。升级前请先阅读[升级指南](./upgrade.md)。

---

## 📋 概述

- 站点配置字段统一：后台站点设置新增版权信息字段，前台 SiteConfig 结构全面对齐后端 `site_*` 命名规范。
- 页脚布局重构：前台友链区域与版权 / 备案信息展示重构，`el-footer` 改为原生 `div`，配套调整 default 与 member 布局。
- 租户时间字段时间戳化：`suspend_time` 由 datetime 改为整型时间戳，迁移中租户起止时间统一为 `bigInteger`。
- 字典表索引调整：唯一索引由单字段 `code` 改为 `group_code + code` 组合，支持不同分组下的同名编码。
- 服务层规范收敛：审核日志服务改用基类 `dao` 属性，修正 `LinkDao` 命名空间指向。
- Windows 兼容性：上传文件静态路由改用 `DIRECTORY_SEPARATOR` 拼接，修复 Windows 下资源访问失败。

## ⚠️ 升级注意事项

1. 数据库变更（需重新执行迁移或手动调整）：
   - `sys_tenant` 表 `start_time` / `expire_time` / `suspend_time` 字段类型由 dateTime 改为 bigInteger，历史数据需转换为秒级时间戳。
   - 字典表唯一索引由 `uk_code(code)` 调整为 `uk_group_code(group_code, code)`，升级前请先排查并清理跨分组的重复编码数据，否则建索引会失败。
2. 站点配置字段重命名：前台 SiteConfig 由 `copyright` / `icp` / `icp_url` / `network_security` / `network_security_url` 重构为 `site_open` / `site_url` / `site_name` / `site_logo` / `site_keywords` / `site_description` / `site_copyright` / `site_record_no` / `site_icp_url` / `site_network_security` / `site_network_security_url`。升级后需在后台站点设置中重新录入版权信息，并确认 `site_setting`（分组 default）数据完整。
3. 前台环境变量：`.env.production` 中 `NUXT_PUBLIC_ROUTING_MODE` 由 backend 改为 hybrid，如生产环境仍需纯后端路由模式，请部署前覆盖该变量。
4. 第三方回调地址：`config/third_party.php` 中微信 `redirect_uri` 端口调整为 8501，请同步更新第三方平台后台的回调白名单。
5. 审核日志批量删除：前端已接入 `batchRemove` 接口（DELETE 携带 ids），需确认后端审核日志模块已提供对应批量删除能力。
6. 前台页脚结构调整涉及 `footer.vue` / `default.vue` / `member.vue`，如有自定义布局覆盖，升级后请回归验证。
