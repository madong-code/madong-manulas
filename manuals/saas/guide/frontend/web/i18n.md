# 国际化

## 概述

`template/web` 使用 **Vue I18n** 实现多语言支持，当前支持：

| 语言 | 标识 | 状态 |
|------|------|------|
| 中文 | `zh-CN` | ✅ 完整 |
| 英文 | `en` | ✅ 完整 |

## 目录结构

```
src/lang/
├── en/                      # 英文语言包
│   ├── common.json           # 通用文本
│   ├── auth/
│   │   ├── login.json       # 登录页文本
│   │   ├── register.json    # 注册页文本
│   │   └── forget.password.json
│   └── member/
│       ├── profile.json      # 个人资料
│       ├── password.json     # 密码修改
│       ├── balance.json      # 余额
│       ├── points.json       # 积分
│       ├── settings.json     # 设置
│       └── sign.json        # 签到
│
└── zh-cn/                  # 中文语言包（结构同 en/）
    ├── common.json
    ├── auth/
    └── member/
```

## 语言包格式

使用 **JSON 格式**，支持嵌套结构：

```json
// src/lang/zh-cn/common.json
{
  "common": {
    "request": {
      "400": "错误请求",
      "401": "未授权，请重新登录",
      "403": "拒绝访问",
      "404": "请求地址出错",
      "500": "服务器内部错误"
    },
    "button": {
      "submit": "提交",
      "cancel": "取消",
      "confirm": "确认"
    }
  }
}
```

在组件中使用：

```vue
<template>
  <el-button>{{ t('common.button.submit') }}</el-button>
</template>

<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t } = useI18n()
</script>
```

## 插件配置（plugins/i18n.ts）

```ts
export default defineNuxtPlugin(() => {
  const i18n = createI18n({
    legacy: false,           // 使用 Composition API 模式
    globalInjection: true,   // 全局注入 $t
    locale: 'zh-CN',        // 默认语言
    fallbackLocale: 'en',   // 回退语言
    messages: {
      'zh-CN': zhCN,
      'en': en,
    },
  })

  return {
    provide: {
      i18n: i18n,
    }
  }
})
```

## 语言切换

使用组合式函数 `composables/lang.ts` 切换语言：

```ts
// src/composables/lang.ts
export function useLang() {
  const { locale } = useI18n()
  const runtimeConfig = useRuntimeConfig()

  // 切换语言
  function setLang(lang: 'zh-CN' | 'en') {
    locale.value = lang
    // 持久化到 localStorage
    localStorage.setItem('locale', lang)
    // 更新 HTML lang 属性
    document.querySelector('html')?.setAttribute('lang', lang.toLowerCase())
  }

  // 初始化语言（从 localStorage 或环境变量读取）
  function initLang() {
    const saved = localStorage.getItem('locale')
    if (saved) {
      locale.value = saved
    } else {
      locale.value = runtimeConfig.public.DEFAULT_LANG || 'zh-CN'
    }
  }

  return { setLang, initLang }
}
```

在组件中使用：

```vue
<template>
  <el-dropdown @command="handleLangChange">
    <span>{{ currentLang }}</span>
    <template #dropdown>
      <el-dropdown-menu>
        <el-dropdown-item command="zh-CN">中文</el-dropdown-item>
        <el-dropdown-item command="en">English</el-dropdown-item>
      </el-dropdown-menu>
    </template>
  </el-dropdown>
</template>

<script setup lang="ts">
import { useLang } from '~/composables/lang'

const { setLang } = useLang()

function handleLangChange(lang: string) {
  setLang(lang as 'zh-CN' | 'en')
}
</script>
```

## 新增语言

1. 在 `src/lang/` 下创建新语言目录（如 `ja/` 日文）
2. 复制 `zh-cn/` 或 `en/` 的 JSON 文件，翻译内容
3. 在 `plugins/i18n.ts` 中导入并注册新语言
4. 在 `composables/lang.ts` 中添加新语言选项

## 新增翻译条目

1. 在对应的 JSON 文件中添加键值对
2. 在组件中使用 `t('key.path')` 访问
3. 确保所有语言文件都包含相同的键（避免回退时的缺失）

## 注意事项

- JSON 文件不支持注释，保持结构清晰
- 键名使用**小驼峰**或**点分隔**（如 `common.button.submit`）
- 占位符使用 Vue I18n 的命名占位符：`{ name: "John" }` → `Hello {name}`
- 复数形式使用 Vue I18n 的复数规则：`t('common.cart', { n: count })`
