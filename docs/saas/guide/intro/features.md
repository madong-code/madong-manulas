# 1.5 核心特征

- **🏢 多租户架构**：支持三种租户隔离模式（字段隔离、表隔离、库隔离），满足不同规模业务需求
- **🔌 插件系统**：完整的插件机制，支持独立安装/卸载/启用/禁用，插件可包含后端逻辑和前端页面
- **🖥️ Web 终端**：基于 xterm.js 的 Web SSH 终端，支持在线执行命令、查看日志
- **⚡ 代码生成器**：14 种代码生成器，支持一键生成 CRUD 全套代码
- **🌐 国际化**：后端 PHP + 前端 Vue 3 完整 i18n 支持
- **📊 动态菜单**：后端驱动菜单渲染，支持插件动态注册菜单
- **🔐 方法级权限**：基于 PHP 8.2+ 原生 `#[Attribute]` 的方法级权限控制
- **📡 SSE 实时通信**：服务端推送，支持实时通知、安装进度展示
- **🎨 Vben Admin 5**：前端框架，基于 Vue 3 + Vite + Element Plus + vxe-table
