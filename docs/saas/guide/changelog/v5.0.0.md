# v5.0.0 更新日志

> 发布日期：2026-06-25

本文记录 v5.0.0 的变更。升级前请先阅读[升级指南](./upgrade.md)与 [v5.0 更新日志](./v5.0.md)。

---

### 新增功能

#### 前端

- **web 应用（Nuxt 4）**：新增用户端 Web 应用模板 `template/web`，基于 Nuxt 4 + Element Plus
- **mono 共用层**：前端文档重构，共同部分独立为 `mono/` 目录，`admin` / `platform` / `install` 只保留差异部分
- **CRUD 组件增强**：新增批量操作、自定义操作列、SSE 推送等高级功能

#### 后端

- **Web 终端**：支持在浏览器中执行 Artisan 命令，无需 SSH 登录服务器
- **插件市场**：支持在线安装、启用、禁用、卸载插件
- **代码生成器**：一键生成 CRUD 全套代码（Controller / Service / DAO / Model / Validate / Migration）

#### 文档

- **完整文档体系**：新增 50+ 个详细文档，覆盖前端、后端、二开等全链路
- **HTML 富文本**：支持 Markdown + HTML 双模式，带导航栏、代码高亮、目录跳转
- **Skills 使用指南**：为 CodeBuddy、Trae 等 AI 编程工具提供规范文档

### 优化改进

#### 前端

- **Admin / Platform 脚手架优化**：新增 `cross-app-skeleton` 规范，支持一键生成新应用骨架
- **API 层统一**：`requestClient` 统一封装，支持 SSE、多租户头注入、错误重试
- **状态管理优化**：`auth store` 支持多租户切换，`notify store` 支持 WebSocket 实时通知

#### 后端

- **配置体系优化**：28 个配置文件统一管理，支持环境隔离、热加载
- **异常处理优化**：15 种异常类 + Handler + Logger，统一错误响应格式
- **数据库规范**：表前缀 `md_`，字段 `deleted_at` 软删除，强制 InnoDB 引擎

#### 开发体验

- **Skills 规范**：69 个 Skills 文档，覆盖后端、前端、跨端全流程
- **代码生成器**：支持从数据表生成完整 CRUD 模块（app + plugin）
- **Lint / Format 工具链**：`oxfmt` + `oxlint` + `eslint` + `stylelint` + `lefthook`，统一代码风格

### 修复问题

#### 前端

- 修复 Admin / Platform 路由重复注册问题
- 修复多租户切换后菜单不刷新问题
- 修复 SSE 连接断开后不重连问题

#### 后端

- 修复 Web 终端在 Windows 下的乱码问题
- 修复插件卸载后路由未清理问题
- 修复多租户模式下分页统计不准确问题

#### 文档

- 修复 HTML 转换脚本的相对路径问题
- 修复导航栏层级显示问题（平铺 → 嵌套树结构）
- 修复代码高亮在 Windows 下的编码问题
