# Mono 国际化配置

本文介绍 mono 下 admin / platform 两个应用**共用的国际化（i18n）机制**。install 应用为独立轻量应用，i18n 见 [Install 应用介绍](./install/intro.md)。

## 国际化方案

mono 应用使用 **Vue I18n** 实现国际化，支持中文（zh-CN，默认）与英文（en-US），可扩展其他语言。

## 文件位置

i18n 文件分两个位置，加载机制不同：

### 1. `lang/` - 应用业务语言包

```
apps/{app}/src/lang/
├── zh-CN/
│   ├── system/                    # 目录仅用于组织，不参与 key 生成
│   │   ├── menu.json              → key prefix: menu
│   │   └── menu.permission.json   → key prefix: menu.permission
│   └── tenant/
│       └── account.json           → key prefix: account
└── en-US/
    ├── system/
    │   ├── menu.json
    │   └── menu.permission.json
    └── tenant/
        └── account.json
```

**特点**：
- 目录仅归档，**不参与 key 生成**
- 文件名支持 `.` 分隔层级（`menu.permission.json` → key 前缀 `menu.permission`）
- 加载器：`loadAppLangLocales()`

### 2. `locales/langs/` - 框架内置语言包

```
apps/{app}/src/locales/
├── index.ts                    # I18n configuration initialization
├── loader/                     # Loaders
└── langs/
    ├── zh-CN/
    │   ├── common.json          → key prefix: common
    │   └── page.json            → key prefix: page
    └── en-US/
        ├── common.json
        └── page.json
```

**特点**：
- 文件名直接作为 key 前缀
- **不支持 `.` 分隔**（`menu.test.json` 被忽略）
- 加载器：`loadLocalesLangs()`

## JSON 文件结构

### `locales/langs/` - 通用翻译

```json
// apps/{app}/src/locales/langs/zh-CN/common.json
{
  "success": "操作成功",
  "loading": "加载中...",
  "operate": {
    "save": "保存",
    "cancel": "取消"
  },
  "crud": {
    "create": "新增",
    "edit": "编辑",
    "delete": "删除"
  }
}
```

使用方式：

```vue
<span>{{ $t('common.success') }}</span>
<span>{{ $t('common.operate.save') }}</span>
```

### `lang/` - 业务模块翻译

```json
// apps/{app}/src/lang/zh-CN/system/menu.json
{
  "name": "菜单名称",
  "code": "菜单标识",
  "status": "状态",
  "sort": "排序",
  "create_time": "创建时间"
}
```

使用方式：

```vue
<span>{{ $t('menu.name') }}</span>
```

## 加载优先级

`loadAllLocaleMessages()` 按顺序 deepMerge，后加载覆盖前：

1. `locales/langs/` → 框架内置通用翻译
2. `lang/` → 业务模块翻译
3. `plugins/**/lang/` → 插件翻译

## 使用方式

### 在模板中使用

```vue
<!-- lang/ example -->
<span>{{ $t('menu.name') }}</span>

<!-- locales/langs/ example -->
<span>{{ $t('common.tips') }}</span>
```

### 在脚本中使用

```vue
<script setup lang="ts">
import { $t } from '#/locales';

const label = $t('menu.name');
</script>
```

### 插值

```json
{ "welcome": "欢迎，{name}！" }
```

```vue
<span>{{ $t('welcome', { name: 'Admin' }) }}</span>
```

## 添加新语言

### 1. 创建语言文件

```bash
mkdir -p apps/{app}/src/lang/ja-JP/system
mkdir -p apps/{app}/src/locales/langs/ja-JP
touch apps/{app}/src/lang/ja-JP/system/menu.json
touch apps/{app}/src/locales/langs/ja-JP/common.json
```

### 2. 配置环境变量

```env
VITE_DEFAULT_LOCALE=zh-CN
VITE_AVAILABLE_LOCALES=zh-CN,en-US,ja-JP
```

### 3. 翻译内容

```json
// apps/{app}/src/lang/ja-JP/system/menu.json
{
  "name": "メニュー名",
  "code": "メニューコード",
  "status": "ステータス",
  "sort": "ソート",
  "create_time": "作成時間"
}
```

## 最佳实践

### 1. Key 命名规范

- 使用小写 snake_case（`create_time`、`batch_delete`）
- 按模块分组（`menu.name`、`menu.code`）
- 支持 `.` 分隔层级（`menu.permission.list`）

### 2. 避免硬编码

❌ **错误**：

```vue
<span>菜单名称</span>
```

✅ **正确**：

```vue
<span>{{ $t('menu.name') }}</span>
```

### 3. 保持 key 结构一致

`zh-CN` 和 `en-US` 的 key 结构必须一致。

### 4. 通用翻译放 `locales/langs/`

通用翻译（操作提示、按钮文本）放 `locales/langs/`。

### 5. 业务翻译放 `lang/`

业务模块翻译放 `lang/`。

### 6. 插件 i18n 同步

编辑前台 web 菜单表单等新增字段时，新增的 i18n key 需同步到插件语言包，否则前端会显示原始 key（插件运行时路径：`apps/admin/src/plugin/portal/*`）。

## 检查清单

- [ ] 通用翻译 → `locales/langs/`，业务模块 → `lang/`
- [ ] `locales/langs/` 文件名不支持 `.` 分隔（如 `menu.test.json` 被忽略）
- [ ] `lang/` 文件名可通过 `.` 分隔做层级（如 `menu.permission.json`）
- [ ] zh-CN 和 en-US 两个目录是否都更新了
- [ ] 组件中的文案是否使用了 `$t()` 而非硬编码
- [ ] key 是否使用小写 snake_case
