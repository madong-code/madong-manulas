## v5.0（初始版本）

### 核心特性

- **后端**：基于 webman 2.x（PHP 8.2）+ ThinkORM + 方法级 `#[Permission]` 属性
- **前端**：Vue 3 + Vite + pnpm monorepo（admin / platform / install）
- **插件系统**：支持插件独立开发、打包、分发、安装
- **Web 终端**：基于 xterm.js，在浏览器中执行 Artisan 命令
- **代码生成器**：一键生成 CRUD 全套代码
- **多租户**：支持 SaaS 多租户模式，数据隔离

### 技术栈

| 层级 | 技术栈 |
| --- | --- |
| 后端框架 | webman 2.x（PHP 8.2） |
| ORM | ThinkORM |
| 方法级权限 | `#[Permission]` 属性（PHP 8.2+ 原生） |
| 前端框架 | Vue 3 + Vite |
| UI 组件 | Ant Design Vue（admin）、Element Plus（platform / install / web） |
| 包管理 | pnpm（monorepo） |
| 数据库 | MySQL 8.0+ |
| 缓存 | Redis |
| 队列 | Redis Queue |
| Web 终端 | xterm.js |
| 代码生成 | Symfony Console |

### 升级指南

#### 从 v5.0 升级到 v5.x

**前端**

```bash
# 更新 pnpm 依赖
pnpm install
# 重新构建 admin
pnpm run build:admin
# 重新构建 platform
pnpm run build:platform
```

**后端**

```bash
# 更新 Composer 依赖
composer install
# 运行数据库迁移
php artisan migrate
# 重启 Web 终端
php artisan web-terminal:restart
```

**配置调整**

- 检查 `.env` 文件，新增 `WEBSOCKET_URL` 配置
- 检查 `config/plugin.php`，新增插件市场配置
- 检查 `config/casbin.php`，确认 RBAC 规则正确

### 已知问题

#### 前端

- [ ] Admin 端在 IE11 下兼容性问题（建议使用 Chrome/Edge）
- [ ] Platform 端 SSE 连接在弱网环境下可能断开

#### 后端

- [ ] Web 终端在 Windows 下执行某些命令可能乱码（建议用 WSL2）
- [ ] 插件市场安装大文件时可能超时（建议分批上传）

#### 文档

- [ ] HTML 版本在移动端显示效果不佳（建议使用 PC 端）
- [ ] 部分代码示例未覆盖所有场景（持续完善中）
