# v5.1.1 更新日志

> 发布日期：2026-07-29

本文记录 v5.1.1 的变更，涉及仓库：`backend`、`template/web`、`template/mono`。升级前请先阅读[升级指南](./upgrade.md)。

---

## 📋 概述

- 内容审核（review）模块：后端数据层 / 接口层 + 前端管理页面，支持审核创建、审批、驳回、取消及归档日志。
- 上传存储抽象重构：统一 `core/io/upload` 抽象与多驱动（Local / Cos / Oss / Qiniu / S3）适配，配置化存储。
- 租户与建库优化：租户有效期改为时间戳解析，建库 schema 错误幂等跳过，订阅 / 租户 / 站点中间件微调。
- 前端构建与组件：platform 构建产物更新、form 编辑器组件接入（Excel 导出作为插件剥离，不再并入框架）、tenant 账号时间戳表单转换。
- 基建与测试：多态映射引导与菜单迁移命令优化、核心接口 / 异常体系、集成与 SaaS 测试补充。

## ⚠️ 升级注意事项

1. 后端新增 `config/review.php` 与审核菜单 / 配置数据，部署后需执行菜单与配置同步（菜单迁移命令 / 数据同步）。
2. 审核模块新增数据表由迁移 `2026_07_22_000001_create_sys_review_tables.php` 创建；原 `2026_07_01` 系统表迁移中已移除 `sys_review` 建表逻辑。
3. 上传存储配置 `config/storage.php` 已重构，升级后请核对存储驱动配置。
4. 租户有效期字段语义由日期改为时间戳，历史数据升级时需注意转换。
5. 前端审核模块与 mono `apps/admin` 审核页面、国际化词条需配套发布（含 platform 构建产物）。
