# v5.1.3 更新日志

> 发布日期：2026-09-02

本文记录 v5.1.3 的变更。升级前请先阅读[升级指南](./upgrade.md)。

---

## 🚀 租户插件体系重构（核心）

### 新增能力

- 租户插件数据模型拆分为「授权治理表 `saas_tenant_plugin`」与「安装运行态表 `saas_tenant_plugin_install`」，授权状态与安装状态彻底解耦
- 新增 `plugin_sync_job` 插件同步任务审计表与 `PluginSyncStatus` 状态枚举
- 新增插件生命周期编排器 `PluginLifecycleOrchestrator`，统一编排安装、卸载与升级流程
- 新增批量执行器 `PluginBatchExecutor`，≤50 租户内联 SSE 输出、>50 租户转队列执行
- 新增 `PluginSyncJobConsumer` 常驻进程消费同步任务（在 `config/process.php` 注册）
- 新增租户插件迁移、菜单、配置三类同步服务，按租户隔离模式（field / database）落到正确的库
- 新增 `TenantPluginManageCommand` 租户插件管理命令，并附带批量升级与升级测试命令
- 租户插件升级判定 `canUpgrade()` 综合平台升级开关、租户忽略版本与版本比较三因子

### 优化重构

- `SystemModel` 实例固定主库连接，`Plugin` / `PluginLog` 改为系统级模型，避免租户库切换污染
- 六个插件生命周期事件新增 `context` 上下文参数（默认 `legacy` 向后兼容），同步监听器对 `orchestrator` 上下文短路，避免批量场景重复同步
- 插件安装、卸载服务同步维护运行态记录；卸载前校验租户占用，命中占用时提示使用级联卸载
- 已安装租户数、可升级租户、活跃插件等运行态查询统一改查 `tenant_plugin_install`

### 问题修复

- 插件迁移日志按连接名分文件存储，修复库隔离租户复用同一份日志被误判为「已执行」而跳过迁移的问题
- 同步插件操作时校验「已授权且已启用」，跳过未授权或未真正安装的租户
- 权限扫描补充 `app/platform/controller` 目录，平台端接口权限可正常采集

## 🏛 平台端（platform）

### 新增能力

- 新增插件租户分发中心：授权信息与分发双页签，提供平台 × 租户矩阵、升级统计、占用清单与依赖检查
- 支持批量升级（SSE 进度）与级联卸载，支持通过 SSE 远程安装平台已装插件到指定租户（可选是否带数据库）
- 新增「我的应用」页面，卡片 / 表格双视图展示已安装应用，通过抽屉承载授权、安装、卸载、升级场景
- 新增 `usePluginMatrix` 组合式函数，一次拉取矩阵数据供主页与抽屉共享

### 优化重构

- 移除插件市场 granted（授权版）死代码，平台侧统一走单体模式
- 表格默认左对齐，字典 / 状态列与时间列自动居中，操作列固定右侧
- 单体版模块市场：分类 Tab 增加图标，数据变化后分页越界自动回到第一页，列表操作改为下拉菜单
- 插件开发列表新增安装状态列，按 `installed_at` 渲染已安装 / 未安装

## ⚙️ 管理端（admin）

### 新增能力

- 模块市场授权版重构为租户版：新增 `market/components/tenant` 组件目录与 `api/app/plugin/tenant` 接口封装，SaaS 模式下自动切换到租户插件市场
- 语言包补充授权状态、更新弹窗与执行日志相关文案

### 优化重构

- 表格操作列默认固定右侧
- 单体版模块市场交互优化（分类 Tab 图标、分页越界回正、操作改为下拉菜单）

## 📦 数据库迁移

- 新增 `2026_09_02_000001_create_tenant_plugin_tables.php`：一次建到最终结构，含幂等判断与存量数据回填
- `2026_07_01_000001_create_system_tables.php` 补充 `sys_plugin` / `sys_plugin_log` 建表语句

### 升级提示

- 需执行 `php phinx migrate` 完成表结构变更
- 需重启服务以加载新增的 `plugin-sync-consumer` 进程（`config/process.php`）
