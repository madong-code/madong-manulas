```
│  │ 控制器层  │  │ 服务层    │  │ DAO 层   │      │
│  └──────────┘  └──────────┘  └──────────┘      │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐      │
│  │ 模型层    │  │ Schema   │  │ 验证层    │      │
│  └──────────┘  └──────────┘  └──────────┘      │

                         ▼

└─────────────────────────────────────────────────────┘
```

## 分层职责

| 层级 | 职责 |
|------|------|
| 控制器层 | 接收请求、参数校验、调用服务、返回响应 |
| 服务层 | 业务逻辑、事务控制、跨表操作 |
| DAO 层 | 数据访问、复杂查询构造 |
| 模型层 | Eloquent ORM、关联关系 |
| Schema 层 | 请求/响应 DTO、OpenAPI 注解 |
| 验证层 | 输入校验规则 |
| 插件层 | 动态注册路由、菜单、权限 |

## 应用边界

- **Admin API** (`/adminapi`)：超级管理员后台接口
- **Platform API** (`/platformapi`)：平台/租户管理员接口
- **Web API** (`/api`)：用户端 C 端接口
