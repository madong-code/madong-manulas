# 1.1 项目概述

## 关于 Madong-Saas

Madong-Saas 是一款开源的多租户 **SaaS 快速开发框架**，定位为企业级云平台架构典范。基于 **webman 2.x（PHP 8.2+）+ Vue 3** 构建，内置完整的多租户架构、RBAC 权限体系、插件系统、Web 终端等企业级功能，提供从零到一的商业项目快速启动能力。

> 项目坚持「取之于开源，回馈于开源」，旨在为开发者节省时间，提供开箱即用的开发体验。

## 核心定位

| 维度 | 说明 |
| --- | --- |
| 架构 | 企业级多租户云平台架构 |
| 后端 | Webman（Workerman 生态高性能常驻内存框架） |
| 前端 | Vben Admin 5（后台/平台）+ Nuxt 4（用户端） |
| 数据库 | MySQL 5.7+ / 8.0+ |
| 性能 | 接口响应普遍 10-150ms，2M 网络环境下 < 300ms |

## 适用场景

- **SaaS 平台**：开箱即用的多租户架构（字段/表/库隔离），快速搭建 SaaS 应用
- **企业后台**：完整的 RBAC 权限 + 菜单管理，适合企业级后台系统
- **插件化系统**：核心工程 + 可选插件，不需要的组件可直接删除
- **快速原型**：代码生成器一键生成 CRUD，大幅缩短开发周期

## 功能矩阵

### 🏗️ 基础架构

| 功能 | 说明 |
| --- | --- |
| 多租户体系 | 产品订阅、初始数据、独立数据源（字段/表/库三种隔离） |
| 权限管理 | 完整 RBAC 权限控制系统（方法级 `#[Permission]`） |

### 🏢 组织架构

| 功能 | 说明 |
| --- | --- |
| 用户管理 | 系统操作者配置中心 |
| 部门架构 | 树形组织管理，支持数据权限 |
| 岗位管理 | 职务体系配置 |

### ⚙️ 系统管理

| 功能 | 说明 |
| --- | --- |
| 菜单权限 | 菜单 / 操作 / 按钮权限精细控制 |
| 角色管理 | 菜单权限分配 + 数据范围划分 |
| 字典系统 | 常用数据标准化维护 |

### 📊 监控审计

| 功能 | 说明 |
| --- | --- |
| 通知公告 | 系统消息发布平台（WebSocket 推送） |
| 操作日志 | 完整记录正常与异常操作 |
| 登录审计 | 包含异常登录监控 |
